# API Patients

Préversion de la documentation pour le futur service de gestion des patients.

| Méthode | Endpoint | Description |
| --- | --- | --- |
| `POST` | `/api/v1/patients` | Crée un dossier patient. |
| `GET` | `/api/v1/patients/{id}` | Consulte un dossier patient. |
| `PATCH` | `/api/v1/patients/{id}` | Met à jour les informations administratives d'un patient. |

Ce fichier sert de point d'entrée documentaire avant la création du microservice.
